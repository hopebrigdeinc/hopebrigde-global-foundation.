# Hopebrigde Global Foundation — Website V4

An introductory and editorial website presenting Hopebrigde Global Foundation, its background, mission, vision, programmes, reported achievements, humanitarian stories and year-end celebration updates.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open the existing GitHub repository.
3. Select **Add file → Upload files**.
4. Upload all contents of this folder, including `assets` (not the outer folder).
5. Commit the changes to the `main` branch. GitHub Pages will redeploy automatically.

## Included
- Home, About, Programmes, Impact, Get Involved, Grants, Stories, Contact, Privacy and Safeguarding pages.
- Responsive layout, mobile navigation and lightweight scroll animations.
- Contact email: hopebrigdeinc@gmail.com.
- Editorial food-distribution photograph supplied for the website.

## Website purpose
This is an introductory and editorial website. It does not include donation collection, payment checkout or fundraising features.
The impact figures, founding year and programme information are presented as supplied by the foundation. Keep the organisation's supporting records and social media activity available for readers who wish to learn more.

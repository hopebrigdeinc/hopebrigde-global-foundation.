# Hopebrigde Global Foundation — Website package

## Upload to GitHub Pages
1. Open your existing GitHub repository: `hopebrigde-global-foundation`.
2. Choose **Add file → Upload files**.
3. Upload the contents of this folder (not the outer folder): all `.html` files, `styles.css`, `script.js`, and the `assets` folder.
4. Commit the changes to the `main` branch.
5. GitHub Pages should redeploy automatically. Refresh the live site after a few minutes.

## Important production limitations
- GitHub Pages is static hosting. This package does not provide secure authentication, protected admin routes, a database, server-side validation, or secure form storage.
- The enquiry forms currently prepare an email draft addressed to `hopebrigdeinc@gmail.com`; the visitor must send it. For true submissions, connect a reputable form service or build a secure backend, then update the privacy notice.
- Do not put API keys, passwords, payment credentials or private tokens in these files.
- No donation/payment checkout is included.

## Accuracy and trust
- The founding year (2018), contact email and proposed programme information were supplied in the brief; confirm them before relying on them publicly.
- The impact figures supplied in the brief are listed on the Impact page as figures requiring verification, not as established achievements.
- No registration number, legal status, awards, donors, partners, completed projects or confirmed office address have been invented. Add these only from official documents.
- The international grant programme is labelled proposed and not open for applications. Do not advertise grants or collect fees unless the programme is formally approved, funded and published through official channels.
- The supplied food distribution photograph is included as an illustrative image. Confirm image ownership/permission, date, location and whether it depicts a foundation activity before making any claim about it.
- Replace illustrative remote photography with owned/licensed images and add appropriate consent for identifiable people, especially children.

## Before launch
- Verify legal identity, registration, governing body, registered address and contact channels.
- Verify every impact metric with source records and a clear reporting period.
- Have privacy and safeguarding policies reviewed and appoint a safeguarding lead.
- Test every page and form on desktop and mobile.
